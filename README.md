# Regulome Analysis

## Use Cases
- Find genes involved in disease X and find out what they do.
- Figure out how a gene is associated with a particular disease.
    - Find disease-associated variants in that gene
    - Find what TFs bind to that gene
    - Find what the gene does (citing research studies)

## Example Pipeline

**Gene A**
1. Find genomic coordinates
2. Find disease-associated variants
3. Obtain relevant regulatory annotations
4. Look at TF-SNP intersections

Example genes:
- TP53 - guardian of the genome
- CFTR - cystic fibrosis gene
